# CAREERIQ AI – AI-Powered Career Development Platform

**Build Your Future. Unlock Your Potential.**

CAREERIQ AI is an AI-powered career development platform designed to help job seekers analyze their resumes, discover relevant job opportunities, identify skill gaps, prepare for interviews, and build professional resumes.

The platform brings multiple career development tools together in one place using Python, Streamlit, and AI-powered capabilities.

## 🚀 Key Features

### 1. Resume Intelligence
- Upload and analyze resumes.
- Extract relevant profile information.
- Identify important skills and resume details.
- Get resume insights.

### 2. ATS & Job Intelligence
- Analyze resume compatibility with job descriptions.
- Generate ATS match scores.
- Identify matched and missing skills.
- Get relevant job recommendations.
- Receive AI-powered resume feedback.

### 3. AI Career Agent
- Get career-related guidance.
- Explore skill improvement opportunities.
- Receive personalized career assistance.

### 4. AI Interview Simulation
- Practice interview questions.
- Prepare for job interviews.
- Improve interview readiness.

### 5. AI Resume Builder
- Create professional resumes.
- Organize education, skills, projects, and certifications.
- Build ATS-friendly resume content.

### 6. Career Analytics
- Explore career-related insights.
- Track career development information.
- View analytical summaries.

## 🛠️ Technology Stack

- **Programming Language:** Python
- **Framework:** Streamlit

## ⚙️ Installation & Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/vaibhavikolte/CAREERIQ-AI.git
```

### Step 2: Navigate to the Project Folder

```bash
cd CAREERIQ-AI
```

### Step 3: Create a Virtual Environment

```bash
python -m venv venv
```

### Step 4: Activate the Environment

**Windows:**

```bash
venv\Scripts\activate
```

### Step 5: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 6: Configure API Credentials

Configure your Gemini API key locally using the secret configuration expected by the application.

Do not upload API keys, passwords, or secret configuration files to GitHub.

### Step 7: Run the Application

```bash
streamlit run app.py
```
